# Échecs à la cul

Version 2 : jeu à deux sur le même écran, inspiré d'un jeu sur steam. Adaptation non officielle, sans IA ni connexion réseau. Les 32 pièces sont présentes.

Déposez index.html, style.css, app.js, engine.js et README.md à la racine du dépôt. Gardez GitHub Pages sur main / (root). Aucune compilation nécessaire. Ouvrir index.html directement permet aussi de jouer hors ligne.

Cliquez une pièce puis sa destination. Les coups illégaux sont exécutés sans avertissement ; l'adversaire doit accuser avant de jouer. Le livre intégré explique les conventions de cette adaptation (châteaux neutres, captures terminales contestées, ascension). Les détails narratifs et la valorite ne sont pas reproduits.

Sauvegarde locale automatique si le navigateur l'autorise. Pas de traçage, de bibliothèque externe ni de clé. La glace n'est pas protégée contre une inspection du code ou de la sauvegarde. Annuler nécessite l'accord des deux joueurs.
