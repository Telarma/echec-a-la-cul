# Échecs à la Troll

Compagnon de plateau en français pour jouer à deux aux Échecs avancés trolls de *King of the Bridge*.

Le site permet de tirer et révéler les cases glissantes, placer les cadeaux de connaissance, mémoriser les fous sortis du plateau, retourner la position et consulter les règles. Il fonctionne entièrement dans le navigateur et conserve la partie localement.
